4 How to install it

Outlook for Mac

  1. Copy the signature above.
  2. Outlook → Settings → Signatures.
  3. Click +, name it YesAgain, click into the big box, press ⌘V.
  4. Add a second one called YesAgain Reply using the short version.
  5. At the bottom under Set default signatures, pick your account, then set For new messages → YesAgain and For replies/forwards → YesAgain Reply.

Outlook for Windows

  1. Copy the signature above.
  2. File → Options → Mail → Signatures → New, name it YesAgain.
  3. Click in the edit box and press Ctrl+V, then Save.
  4. Repeat for YesAgain Reply, then set both defaults in the dropdowns at the top right.
  5. If the logo doesn't come across, drag yesagain-logo.png into the box and set its width to 112 pixels.

Outlook on the web

  1. ⚙ Settings → Mail → Compose and reply (or search "signature" in Settings).
  2. Add signature, name it, paste, and tick the default boxes. Save.

Apple Mail

  1. Mail → Settings → Signatures.
  2. Select your account on the left, click +, and rename it YesAgain.
  3. Untick "Always match my default message font" — this is the step people miss. Leave it on and Mail strips the design down to plain Helvetica.
  4. Click into the right-hand box and press ⌘V.
  5. Pick it under Choose Signature for that account.

iPhone & Android

Outlook mobile pulls your signature down from the server automatically once it's set in Outlook on your computer or on the web — usually within a few minutes. If it hasn't appeared, close the app fully and reopen it. Apple Mail on iPhone doesn't sync, so use the plain-text version there: Settings → Apps → Mail → Signature.

The two optional fields

Second phone and LinkedIn are optional. Leave either one empty and it simply will not appear — no gap, no blank line, no "N/A". Only add a LinkedIn profile if it is current and presentable; a neglected profile on a company signature reads worse than no link.

If something looks wrong

  • Everything went plain — the "match my default font" box is ticked in Apple Mail, or you used Paste and Match Style. Undo, untick it, paste again with plain ⌘V.
  • Logo missing — your mail app blocked the image on paste. Drag yesagain-logo.png in and size it to 112px wide.
  • Fonts look different to the preview — that's normal and fine. The signature is built to fall back to Georgia and Helvetica, which every mail app has.
