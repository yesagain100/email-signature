# YesAgain Email Signature

Company email signature generator for YesAgain Group staff.

**Live page:** https://yesagain100.github.io/email-signature/

Each person fills in their name, job title, mobile and email, then copies their
signature and pastes it into Outlook or Mail. Everything else — logo, layout,
certifications, award, locations, both storefronts — is generated identically
for everyone.

Self-contained single page: the logo is embedded, so it works offline once loaded.
